# 前端优化实施与验证记录

完成日期：2026-10-13。对应 [前端分析报告](FRONTEND_DESIGN_REVIEW.md)。修改实际 `public` 业务页面，沿用原生 JavaScript、Chart.js 和现有 API，没有引入新的前端框架、外部字体或在线素材。

后续的展示复核和第二轮改进见[第二轮前端展示分析与实施](FRONTEND_PRESENTATION_REVIEW_ROUND2.md)。本文件保留第一轮实施记录。

## 完成项

| 分析中的问题 | 实施结果 |
| --- | --- |
| 首屏控件密集，日期位于 KPI 后方 | 主导航简化为今日、趋势、项目、画廊；主题与计价归入设置；日期范围前置；默认近 30 天；完整金额口径可展开查看。 |
| 手机 Timeline 横向溢出 | 来源选择在自身区域横向滚动，控件按断点换行；表格独立滚动；四个视图检查 320/390/768/1440px。 |
| 每次销毁重建图表 | Chart.js 保留同一实例更新，来源可见性按稳定名称保存；主题更新不重播入场；日期垂线、排序 tooltip、低噪声网格与直线段。 |
| 图例注入未使用模型，Token 排名按金额 | 仅绘制当前范围活跃来源；模型按当前单位排序，可显示前 8、前 16 或全部；模型线型与点型补充区分。 |
| 固定 Gemini KPI 与混合单位 | 第四卡换为活跃天数及活跃日均 API 等值；主值只显示一种数字；更新采用 400ms 数值过渡。 |
| 明细和工程页面过长 | 明细 25 行/页、工程 12 个/页、画廊 24 张/页；搜索和筛选重置页码，刷新保留页码；明细提供日期/金额/Token 排序。 |
| 图库总数超过最近 100 张预览，旧图搜索不到 | 新增 `/api/codex-images` 完整元数据索引；只在打开图库时按需读取，总览仍仅传最近 100 张。图库分页、日期筛选、搜索与灯箱覆盖全部索引，索引读取失败有独立提示与重试。 |
| 搜索重建全部卡片、重绘隐藏 Timeline | 搜索 160ms debounce；工程和图片卡片按稳定键复用，仅可见移动项做排序位移动画；只渲染当前视图。 |
| 写死首屏数量与不完整加载反馈 | 数值使用未知占位；首次读取有固定高度骨架；刷新保留内容、禁用重复刷新、转动刷新图标。 |
| 旧响应覆盖新筛选 | AbortController 与请求序号共同保护，旧响应不能覆盖新选择。 |
| 永久绿色“实时”状态 | 统一读取中、读取成功、数据过期、读取失败；显示最后拉取时间及日志覆盖日期；五分钟后提示数据过期。没有自动读取轮询。 |
| 空状态、错误状态缺恢复入口 | 表、图表、工程、画廊、价格搜索分别提供清除筛选、查看全部或重试；网络失败保留并标记上次成功数据。 |
| 自定义日期和纵轴值无校验 | 开始晚于结束、日期不完整、非正或无效纵轴上限就地提示；无效输入不改变已显示范围或图表。7/30 天按包含结束日计算。 |
| 页签及详情直接切换 | 滑动选中背景，视图 160ms 轻淡入，工程和模型族详情高度/透明度过渡，展开状态有 ARIA 语义。 |
| 图片直接开新标签页 | 原位灯箱：缩略图过渡、前后切图、键盘方向键、缩放与拖拽、Prompt/日期/大小、原图和下载、加载失败重试、相邻图片预载。 |
| 弹窗无统一焦点和退出反馈 | 共享弹层生命周期，处理 Escape、Tab 范围、焦点恢复、背景 inert、滚动锁、嵌套层级及退出动画；参考费率使用右侧面板。 |
| 浅色覆盖重复及硬编码深色 | 收拢表面、文字、边界、阴影、间距、圆角与动效 tokens，减少重复主题规则；组件使用主题变量，删除重复 keyframes 与 transition: all。 |
| 减少动画仅影响 CSS | CSS、数字动画、视图、排序、灯箱、详情和 Canvas 图表都遵守 prefers-reduced-motion；页面隐藏时暂停无必要动画。 |
| 模型族生图金额不随日期范围变化 | 生图族只计所选日期范围，且只在全部/Codex 来源中纳入；没有消耗的预设模型不再伪装成活跃排名。 |

## 主要文件

- `public/index.html`：页面结构、筛选层级、可访问名称、分页区域与灯箱结构。
- `public/styles.css`：统一主题、控件和数据区样式、响应式断点、动效与状态。
- `public/experience.js`：独立的数值动画、导航、状态、焦点管理、弹层与灯箱辅助函数。
- `public/app.js`：请求顺序、图表更新、分页、筛选、输入校验和业务数据渲染。
- `codex-image-adapter.js`、`unified-server.js`：缓存完整图片元数据索引与按需读取接口。
- `tests/frontend-ui-check.py`：基于确定性 API fixture 的浏览器回归检查。

## 验证

1. `npm test`：70 项通过，零失败，含完整图片索引与预览大小的 API 回归。
2. `python tests/frontend-ui-check.py`：11 组通过。覆盖 32 组宽度/主题/视图组合、键盘导航、图表实例与显隐保持、当前单位排名、反序日期、三类分页与空状态、弹窗焦点、灯箱操作及失败重试、请求竞态及旧数据保留、减少动画。额外检查包含区间边界、明细排序、生图的日期范围、过期提示、无效纵轴、图片节点复用、缩略图重试及完整图库的延迟读取、旧图搜索、日期筛选与失败重试。
3. 真实本地数据：另检查四个视图 × 四种宽度 × 明暗主题共 32 组布局，未发现整页横向溢出；检查价目面板、灯箱和数据过期提示，未出现页面脚本异常。真实数据截图作视觉复核。

运行浏览器检查需要 Python Playwright 及 Chrome。项目仍用 `npm start` 启动；检查默认访问 `http://127.0.0.1:4242`，可通过 `--base-url` 调整。它用合成响应验证交互，不需要真实日志。单组检查与截图参数见 `python tests/frontend-ui-check.py --help`。

统计仍使用原有 API 数据。订阅费用、自定预算、额度历史、未知价格和正文估算的口径说明继续保留；界面动效不会改变金额计算。
