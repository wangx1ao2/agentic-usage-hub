# 第二轮前端展示分析与实施

日期：2026-10-13。依据当前工作区、独立代码复核及真实本地数据页面。改动已落实到业务页面，保留第一轮的分页、图表实例、动效、灯箱、请求顺序保护和焦点管理。

## 分析与逐项优化

| 观察到的问题 | 已完成的展示优化 | 对应位置 |
| --- | --- | --- |
| 项目“重点聚焦”与来源数量一直是占位 | 主要消耗工程按当前筛选计算，显示金额和占比；空结果显示暂无工程；来源标题显示实际活跃数。 | `renderProjects`、`renderCompanyGrid` |
| 日期和生图入口占用首屏，图表缺少筛选上下文 | 常用范围保留，自定日期进入可展开面板；删除重复画廊入口；图表旁显示完整日期、来源、单位、可见曲线数量及对数状态。 | `index.html`、`updateChartContext` |
| 趋势把不连续日期等距相邻排列 | 在已知数据范围内按日历补足中间日期；没有记录的日期使用 null，相邻记录点连续连接，不制造零值；跨年横轴保留年份，孤立日期显示点。 | `calendarTimeline`、`renderChart` |
| KPI 只有大数字，缓存名称与计算不一致 | 增加使用同一日期数据的轻量趋势小图；缓存统一称读取占比；总 Token 明示含输入、输出及缓存；主指标保留实际数值提示。 | `renderMetrics`、`renderSparkline` |
| 来源构成大量零值卡，难比较 | 默认展示活跃来源的排名、金额/Token、占比条和活跃日；零值折叠成未使用来源；排名随当前单位切换。模型族排序同步单位。 | `renderCompanyGrid`、`renderModelRanking` |
| 工程路径重复、混用亿与 M/B、不知道各项目权重 | 路径只保留一处并缩短，完整路径仍可查看/复制；标题支持两行；统一 Token 格式；加入排序位置及当前筛选内金额占比；修正 Grok 等 Agent 标签。 | `renderProjects`、`compactDisplayPath`、`copyProjectPath` |
| 图库裁掉海报，通用 Prompt 无法区分资产 | 默认完整预览，也可切换铺满且记住偏好；尺寸来自图片 naturalWidth/naturalHeight，未加载时不猜测；通用 Prompt 使用短文件名，完整文件名可查看；不为切换布局重载图片。 | `renderStudioGallery`、`setGalleryFit`、`handleThumbnailLoad` |
| 实测模型 Token 与生图折算值混合，图库有不准确“官方额度”文案 | 今日主 Token 指标只显示模型 Token；生图卡与模型详情单独标明 Token 等值；模型族 Token 合计不再加入图像折算；图库说明按张数折算、不代表官方额度。 | `renderTodayDashboard`、`renderModelRanking`、图库指标 |
| 今日工程列表可不断增长，把图像挤远 | 显示活跃工程数，预览最多五个，路径与累计金额分开；入口直达今日工程筛选；模型先展示前六个，其余可展开；图片成果有独立分隔。 | `renderTodayDashboard`、`showTodayProjects` |
| 有 Token 但未定价可能看起来为零消耗，纵轴截断没有提示 | 未知金额使用未知/未定价说明，金额明细与模型详情明确缺价格；金额图提供 Token 入口；纵轴超过显示上限时提示并可恢复；小额正金额与真正零值区分。 | `formatUSD`、`renderMetrics`、`renderTable`、`updateChartContext` |
| 模型排名容器的 flex 收缩裁切文字 | 取消外层固定高度压缩，卡片保持真实高度；较长的模型明细只在其自身区域滚动，标题和汇总不裁切。 | `styles.css` 中 model-list / family-card / family-sub-list |

所有时间、排名和占比均来自已有数据。按用户反馈修复折线断开后，主图与指标小图均连接相邻记录点；缺失日期仍保留空值，不计为零，不生成数值或计入汇总，日期间距保持真实日历跨度；数据起止范围之外不推算。图像像素尺寸只在浏览器完成加载后显示。

## 展示口径变化

今日的主 Token 数字现在是模型 Token，不再混加图片数量折算出的 Token 等值。图片等值仍在生图卡与图库中保留。模型族同样将实际 Token 与图像等值分开。底层日志、模型计价、订阅费用、额度历史及项目身份均未修改。

来源与工程的占比以当前筛选结果为分母，翻页不改变分母。工程金额是累计 API 等值，今日工程列表明确注明累计，避免误读成今日金额。没有模型费率的记录不被解释为免费。

## 验证证据

- `npm test`：70 项通过，零失败。
- `python tests/frontend-ui-check.py`：15 组通过。继承原有交互回归，并新增筛选后的主要工程、来源计数/占比/排序、未定价展示、日历空值/跨年/连续连线、隐藏系列摘要、上限提示、完整预览与尺寸、图片节点复用、今日工程跳转、复制原始路径等验证。连续连线检查实际绘制的线段，覆盖金额/Token、来源/模型与普通/对数刻度。
- 真实数据：四视图 × 四宽度（320 / 390 / 768 / 1440）× 明暗主题共 32 组布局通过；自定日期面板另做 8 组边界检查；未发现页面脚本异常。
- 视觉复核：检查桌面/手机总览、完整来源与模型区域、今日工程与图片区域，以及明暗图库；修复发现的内部裁切与元数据换行问题。

浏览器回归使用合成数据，不将测试路径写入系统剪贴板；复制检查验证请求使用完整原始路径。真实数据截图用于视觉复核，位于本地 `.cache/frontend-audit/round2`。
