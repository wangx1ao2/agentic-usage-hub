# 项目展示区局部优化实施记录

执行范围依据用户确认的局部方案；以第20版恢复后的站点为基线，该版本内容与第18版相同。

## 已实现

- 项目区默认展示12张独立概览卡片，三个精选置顶。完整卡片表面、清晰边框与24–28px间距区分项目。
- 点击后，在该卡片所在行下方展开一个详情面板。展开新项目会收起旧项目并暂停视频。
- 视频与功能界面共用展示区域，通过标签切换；全部截图与技术说明默认折叠。
- 面板顶部与底部均有收起入口；收起恢复卡片焦点与滚动位置，匹配的搜索和分类条件保留。
- 保留12个项目、5段视频、99张截图、3条技术流程以及原有项目链接。视频按需播放，不自动下载整段视频。
- 继续使用原生视频控制、原有截图图集、缩放、模块选择、快捷搜索与系统减少动态效果设置。

## 范围核验

- 渲染后的项目区之前与之后的HTML，均与基线逐字比较一致。
- 原有8份CSS、首页交互、经历交互、图集、快捷搜索、动效主模块、数据文件及构建配置保持不变。
- 新CSS的每个选择器均限定在 `#project-work` 下。
- 首屏、导航、工作方式、能力、经历、联系及页脚的13组代表元素，其字体、颜色、布局尺寸等计算结果与改动前完全一致。
- 共享导航及动效适配只接入项目面板展开/收起、媒体切换与遮挡检测；没有替换其他页面区域。

## 验证

- TypeScript检查、生产构建与内容校验通过；保留截图文件的哈希一致。
- 12个项目均能独立展开；同一时间只有一个面板可见。
- 1440×900、1366×768、1280×600、1024×768、768×1024、390×844、360×800尺寸均无横向溢出。
- 验证焦点和滚动恢复、搜索/分类保留、卡片再次点击收起、视频与截图切换、截图选择与图集放大、技术节点切换、旧链接。
- 开启动效时验证首页项目切换、能力跳转、快捷搜索及收起位置恢复；5段视频均实际解码播放且收起暂停，系统减少动态效果生效，无浏览器脚本错误。
- 修正手机悬浮目录遮挡收起按钮的问题，遮挡时目录自动隐藏。

浏览器核验结果与截图位于 `output/project-section-only/`。
