# 仅优化项目展示区：范围与方案

用户最新要求优先：撤销上一轮整站改造，先恢复第18版，再提出项目展示区的局部方案。本文件取代上一份方案中涉及首页其他区域的改动建议；本轮不实施新展示方案。

## 固定范围

以恢复后的第18版为基线。保留原有导航、首屏文案与三维展示、工作方式、能力、经历、工具范围、联系方式、页脚及对应交互。

优化范围仅包含原来的「项目目录、精选案例、更多应用」三个项目展示区域。项目数据、12个项目、5段视频和99张截图保留。共享样式不整体替换，新样式限定在项目区根节点，防止影响其他区域。

## 推荐：概览卡片 + 单项目展开面板

首页项目区先展示12张摘要卡片，三个精选项目置顶并标记。初始不展开完整案例。

卡片包含：编号、项目名称、一句用途、一张代表封面、真实状态、两项技术标签、视频时长及「展开项目」入口。用完整浅色卡片表面、清楚的边框和24–32px间距明确项目边界，延续原站字体与配色。

点击卡片后，在项目区内展开对应项目的详情面板。同一时间最多展开一个项目，其他项目保持概览；展开新项目会收起前一个并暂停其视频。详情面板与卡片通过名称、编号和边框清楚关联。

面板顶部和底部均提供收起入口。收起后回到所选卡片，保留原来的分类、搜索、焦点和浏览位置。已有项目锚点继续定位并展开对应项目，避免历史分享入口失效。

## 控制单个项目的信息量

| 内容 | 默认呈现 |
| --- | --- |
| 项目名称、简短用途、我的工作、真实状态 | 展开后直接可见 |
| 视频或代表截图 | 一个展示窗口；有视频时默认视频封面 |
| 视频 / 功能界面 | 同一窗口切换，不上下堆叠 |
| 三个核心功能节点 | 简短按钮，可切换对应界面 |
| 技术实现与验证依据 | 默认折叠 |
| 全部截图 | 默认折叠，入口标明张数，点击后使用原有图集 |

继续保留第18版按窗口高度适配的媒体尺寸、原生播放和放大入口，避免单个展开面板再次变成长篇资料堆叠。

## 验收条件

1. 非项目区域的HTML、文案、组件样式与交互同第18版一致，验证时逐区域比较；不得重新设计全站头部、首屏、经历或联系区域。
2. 初始只显示概览，同一时间最多展开一个项目。
3. 项目边界、展开与收起入口在桌面和手机上清楚可辨。
4. 展开、切换、收起后，筛选、搜索、滚动位置与焦点正确；关闭项目会暂停视频。
5. 原有12项目、5视频、99截图及旧项目锚点完整可用。
6. 新增CSS限定在项目区域，不引入全局字号、配色、页面宽度与其他区域的布局调整；手机和桌面均无横向溢出。
