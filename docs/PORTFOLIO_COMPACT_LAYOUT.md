# 作品集展示尺寸优化

2026-10-19，修改「钟育文 · AI 应用作品集」原站点。

问题：整列视频与截图按页面宽度自然放大，1366×768 窗口中，单独的视频卡片约 855px 高，截图展示区约 1114px 高，需要浏览器缩小才能获得整体印象。

调整：

- 精选项目与有视频的展开项目，在桌面端并排展示简介和视频。
- 视频宽度同时受容器宽度及窗口高度限制；保留完整 16:9 内容与原生播放控件，增加「放大播放」按钮，使用浏览器全屏，不触发自动播放。
- 十二个项目截图区在桌面端改为截图与说明并排；按窗口高度限制截图画框，使用 contain 完整呈现截图。缩略图继续可拖动、可点击，模块选择、图集缩放与原图入口保留。
- B2B 改为紧凑的点击切换界面，取消需要多屏滚动的说明栏及关联自动切图；普通过渡动效保留，关闭动效时布局不变。
- 手机端使用上下布局，收紧间距与画框比例，保留可触摸的播放及放大入口。
- 限制首屏旋转装饰的溢出范围，避免较矮桌面窗口产生横向滚动空间。

结果：1366×768 窗口中，精选项目的简介与视频整体约 643px 高，截图展示区约 598px 高，均可在固定导航下完整浏览。

验证：

- 构建和 TypeScript 通过；十二个项目、九十九张截图、五段视频与原有技术流程通过内容核验，截图摘要一致。
- 浏览器检查 1366×768、1280×600、1440×900、1024×768、768×1024、390×844，共 72 个项目与窗口组合，无横向溢出。桌面截图区与精选概览在可用窗口高度内。
- 原生全屏、退出全屏、实际播放、功能节点切换、图集放大/重置/退出，以及关闭动效后的布局通过；等待加载后滚动位置和文档尺寸稳定。
- 播放前无 MP4 请求，无页面脚本异常。
