# AI 作品集：首页与项目详情结构方案

日期：2026-10-19。交付为方案与本地交互样稿，正式站点保持第 18 版。

## 推荐结论

采用「首页项目卡片 → 独立项目详情页」，在详情页内部对技术说明与完整截图使用折叠。主页承担发现、筛选和比较项目的任务，详情页承担观看演示、理解本人贡献和核验实现的任务。

上一轮处理了播放器尺寸和截图高度；截图中的两个问题仍与信息结构有关：首页同时包含目录、完整案例和工程资料；项目之间和项目内部又都使用浅绿色背景、细边框与相似的面板，视觉层级接近。

## 三种方案比较

| 方案 | 优点 | 主要代价 | 判断 |
| --- | --- | --- | --- |
| 首页每个案例做手风琴 | 修改较少，可快速减少初始长度 | 展开后首页再次变长，比较项目与继续浏览时需要反复收起 | 适合作为过渡 |
| 点击卡片打开大弹窗 | 保持列表位置，适合短预览 | 长案例在弹窗内产生额外滚动，手机、返回和直接分享需要更多处理 | 用于图片或视频预览 |
| 独立项目详情页，次要资料折叠 | 首页保持稳定；每个项目边界明确；可分享、直接打开和浏览器返回 | 需要生成详情页面并兼容旧链接 | 推荐最终方案 |

## 首页的内容取舍

主页顺序：简短个人定位 → 统一项目区 → 精简能力/经历 → 联系方式。

- 现有 12 个项目只出现在同一套目录中。现有三个精选项目置顶并标记；其余九个继续在同一网格中展示，避免「目录一遍、精选长案例一遍、更多项目再一遍」的重复。
- 每张卡片包含：编号、项目名、一句价值说明、一张代表封面、两个主要技术标签、真实状态、详情入口。
- 五个有视频的项目在封面标注「25 秒演示」等实际时长。首页使用封面，进入详情即可主动播放，不自动下载 MP4。
- 首页撤去项目内缩略图长条、完整实现路径、工程说明和完整截图列表，资料全部保留在详情页。
- 搜索、分类筛选覆盖全部 12 个项目；筛选后的列表保留精选排序，不在另一处重复渲染精选项目。

## 项目边界与视觉层级

- 页面使用低对比中性背景，项目卡片使用完整白色表面，内部不再嵌套多层相同的绿色卡片。
- 项目卡片建议间距 24–32px、内边距 18–24px。边框、轻阴影和顶部色标共同形成边界，色标只辅助识别，项目名称和编号始终存在。
- 桌面三列、平板两列、手机单列；封面比例统一，以完整呈现内容为优先。
- 卡片高度由一致的封面与摘要额度控制：简介最多两行、标签最多两个。不要通过无限缩小正文来压缩高度。
- 整张卡片是进入详情的单一主要动作。悬停位移保持轻微，触摸端通过明确的「查看项目」文字提供入口。
- 页内只保留已验证不会改变文档尺寸的动效，避免加载、悬停或展开时引起滚动空间波动。

## 详情页的默认与折叠

| 内容 | 默认状态 | 原因 |
| --- | --- | --- |
| 项目名称、问题与价值、本人职责、技术重点 | 直接可见 | 读者需要迅速判断作品及作者贡献 |
| 当前交付状态与演示范围 | 直接可见 | 区分本地应用、模拟接口和真实生产成果 |
| 代表视频或代表截图 | 一个展示区直接可见 | 保留已有演示素材的价值 |
| 三个核心功能节点 | 直接可见、简短 | 建立功能全貌与阅读路线 |
| 视频 / 功能界面 | 同一区域切换 | 避免把相近内容前后重复堆叠 |
| 实现过程与验证依据 | 默认折叠 | 面向需要深入核验的读者 |
| 全部功能界面（显示张数） | 默认折叠，可进入图集 | 99 张截图有清楚入口，同时控制默认阅读长度 |
| 返回目录、下一个项目 | 明确可见 | 完成一个案例后继续探索 |

详情页沿用当前按窗口高度适配的媒体尺寸与放大能力。移动端使用上下结构，页面只显示一个项目；项目切换后暂停前一个视频。

## 导航与实现安排

- 首页卡片主链接建议为 `/projects/hub/` 等独立地址；详情页提供「作品 / 项目名称」和「返回项目目录」。不必打开新标签页。
- 返回时恢复首页的搜索词、分类、滚动位置与卡片焦点。刷新和直接打开详情地址也应正常工作。
- 旧 `#project-hub` 等分享链接兼容跳转到对应详情页，避免历史入口失效。
- 复用当前 `portfolio.json`、五段视频、99 张截图及图集能力；从同一数据源生成首页卡片和详情页，保持资料一致。
- 第一阶段拆分页面和迁移内容；第二阶段统一卡片视觉并精炼摘要；第三阶段检查返回状态、旧链接、视频加载、移动端与静态动效模式。
- 静态详情路径的直接访问和刷新行为，在正式实现时以实际部署测试验证。

## 验收目标

1. 首页每个项目只显示一次，不出现展开的长案例或完整截图轨道。
2. 首页能快速比较项目，任一项目详情只需一次点击进入；每张卡片的名称、状态和入口可辨认。
3. 每个详情页只显示一个项目的内容；返回目录、继续浏览入口明确。
4. 重要摘要和状态无需展开；完整技术资料与全部截图入口可发现。
5. 原有五段视频与99张截图完整保留，首页播放前不请求 MP4。
6. 手机、平板、桌面均无横向溢出；返回列表恢复原来的筛选与浏览位置；常规加载期间滚动空间稳定。
