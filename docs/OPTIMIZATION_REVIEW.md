## 审查发现与修正

- ccusage 诊断覆盖仅取其自身日期，避免混入其他来源；未返回的来源路径不猜测。
- 首次手动刷新失败也保留之前被动读取的成功时间；被动恢复可清除过期失败状态。
- Codex 工程移除固定缓存比例；不能核对的明细不重复计入总量、不按比例摊派。
- 额度美元历史随价格选择重算，并保留速度元数据，避免与同页看板价格口径冲突。
- Claude 缓存写入不丢计数；目录金额明确标为估算。未知模型、对象原型同名模型和未知费率不会借价或变成免费。
- 日期缺失不会产生虚构精确时间；CSV 保留估算参数。损坏的完整 Codex 用量行导致明确失败并保留旧快照，未完成尾行单独报告。
- Worker 观察超时不终止实际索引；失效前的请求不能复活旧缓存；关闭时收敛持久化，子进程随 IPC 断连退出。
- 价格文件采用原子写和进程/线程锁，独立实例合并版本；损坏文件不被静默覆盖。
- ES Modules 统一入口 URL，消除重复状态实例；保留现有内联入口兼容，静态模块重验证。
- 中英文 README、环境变量、API 和价格说明已同步实际实现。
