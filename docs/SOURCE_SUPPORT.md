## Claude 兼容网关身份限制

有 requestId 时，使用 requestId 与 messageId 的组合，避免同一消息名出现在不同请求时被合并。同一请求的流式快照保留完整计数。缺少 requestId 时按会话内消息 ID 去重；非 `msg_` / `resp_` 的兼容网关 ID 会在诊断和记录的 `pricingContext.usageIdentity` 中提示身份假设。

本机兼容日志与 ccusage 20.0.51 在这一情形下存在已确认的统计差异：上游给自定义 ID 加入时间戳，本项目把同一消息的重复完整用量快照合并。依据：[对应上游实现](https://github.com/ccusage/ccusage/blob/v20.0.51/rust/adapters/claude/src/lib.rs)。如果网关确实在多个请求中复用同一 ID，现有日志不足以恢复精确请求数；应让采集端保存真实请求 ID，不能靠比例推算。
